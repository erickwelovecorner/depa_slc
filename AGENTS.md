# depa-csl

Repo de contexto de diseño para el departamento **depa-csl**.

Este hilo y estos docs aterrizan **refs → concepto → aplicación en el depa real**. No es (aún) un repo de obra ni de app.

## Cómo trabajar aquí

- Las refs van en `refs/<zona>/`.
- El aterrizaje de cada zona va en `docs/zonas/<zona>.md`.
- El concepto global (cuando exista) vive en `docs/ESTILO.md`.
- No mezclar moodboard con el depa actual hasta que el estilo de la zona esté escrito.
- Al implementar o recomendar para el depa real, partir de `docs/zonas/` y de las restricciones que se documenten después (fotos, medidas).

## Estado

- Living / sala: refs recibidas, estilo aterrizado.
- Resto de zonas: pendiente.
